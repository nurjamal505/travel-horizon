# Настройка Telegram (без программирования)

Токен бота даёт полный контроль над ботом. Не вставляйте его в код сайта, GitHub, скриншоты и чаты.

## 1. Создайте бота
1. В Telegram откройте **@BotFather** (с синей галочкой).
2. Отправьте `/newbot`, выберите имя и username, оканчивающийся на `bot`.
3. Скопируйте токен и сохраните в менеджере паролей.

## 2. Запустите бота
Откройте своего бота и нажмите **Start** (или отправьте `/start`). Иначе бот не сможет вам писать.

## 3. Узнайте Chat ID
**Личный чат:** напишите боту любое сообщение. На своём компьютере выполните в терминале (замените `TOKEN`):
`curl "https://api.telegram.org/botTOKEN/getUpdates"`
Найдите `"chat":{"id":123456789,...}` — это и есть Chat ID. Не публикуйте эту ссылку и ответ.

**Группа:** добавьте бота в группу, напишите там сообщение и повторите команду. ID группы обычно отрицательный (например `-1001234567890`). У бота должно быть право писать в группе.

## 4. Переменные в Vercel
Vercel → ваш проект → **Settings → Environment Variables**. Добавьте для **Production** и **Preview**:

| Имя | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен от BotFather |
| `TELEGRAM_CHAT_ID` | Chat ID из шага 3 |
| `NEXT_PUBLIC_SITE_URL` | адрес вашего сайта (сейчас кодом не читается, нужен на будущее) |

После изменения переменных сделайте **Redeploy** (Deployments → ⋯ → Redeploy): старые деплои их не видят.

## 5. Проверка
1. Отправьте тестовую заявку на опубликованном сайте — сообщение должно прийти в Telegram.
2. Отправьте форму без согласия, без телефона и email — должны появиться ошибки, в Telegram ничего не приходит.
3. Проверка сбоя: временно поставьте неверный `TELEGRAM_CHAT_ID`, сделайте Redeploy, отправьте заявку — сайт должен показать ошибку, а не успех. Верните значение обратно.
4. В DevTools → Network убедитесь, что запрос идёт на `/api/booking` и токена нигде нет.

## Частые проблемы
- **Ошибка при отправке, в логах Vercel «chat not found»:** неверный Chat ID, не нажат Start или бот не в группе.
- **Ответ `not_configured`:** переменные не заданы или не было Redeploy.
- **Пустой `getUpdates`:** сначала отправьте боту новое сообщение.
- **Токен утёк:** в BotFather выполните `/revoke` и обновите значение в Vercel.
